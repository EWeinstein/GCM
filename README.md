# GCM
Code reproducing the simulations, models and analysis in Geometric Causal Models, Weinstein and Blei, 2026

The files `spatial_gcm.py`, `array_gcm.py` and `genomic_cate.py` contain the core code used in the paper for sections 5.3, 5.4 and 7 respectively. The corresponding .sh files (`run_spatial_gcm.sh`, `run_array_gcm.sh`, `run_genomic_cate.sh`) contain the command line parameter configurations used. The corresponding notebooks (`summarize_spatial_gcm.ipynb`, `summarize_array_gcm.ipynb`, `summarize_genomic_cate.ipynb`) plot the results. The `results.pkl` files in `array_results` and `spatial_results` are the results used for the manuscript, and can be plotted with the corresponding notebooks. The input genome data for the genomic example is at `data/tert.fa`, while the output results file used for plotting is too large for github, and instead can be found at this google drive [link](https://drive.google.com/file/d/1cKXw_D18J1GDs60jFOD7o1hJdx3Z0qxc/view?usp=drive_link).
